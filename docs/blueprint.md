# **App Name**: Sahayak.AI: Teaching Partner

## Core Features:

- Hyperlocal Content Generator: Generate culturally relevant stories and content in the local language based on voice or text input from the teacher using Gemini 1.5 Pro.
- Differentiated Worksheets from Image: Generate tiered worksheets (easy, intermediate, advanced) from a photo of a textbook page, using Gemini Vision and Gemini Pro to classify concepts.
- Knowledge Assistant in Local Language: Answer student questions in the local language with simple explanations and analogies using Gemini Pro and translation APIs.
- Visual Aid Generator: Generate blackboard-friendly SVG sketches or stepwise drawings from text prompts using Gemini Vision. A tool for prompting Gemini and retrieving the sketches will be incorporated.
- Audio Reading Assessment: Assess student reading fluency by comparing their voice input to a script using Vertex AI Speech-to-Text.
- Auto Lesson Planner: Generate time-structured, level-wise lesson plans from a weekly syllabus using a Gemini Pro prompt.
- Gamified Learning Mini-App: Tool that leverages Gemini-generated content and hosts an interactive page.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to convey trust and intelligence, nodding to the seriousness of education while still feeling modern.
- Background color: Very light lavender (#F0F8FF), a desaturated tint of indigo, offering a clean, non-distracting backdrop.
- Accent color: Bright, contrasting yellow (#FFD700) for key interactive elements, injecting a sense of vibrancy and engagement.
- Body font: 'Inter', sans-serif
- Headline font: 'Space Grotesk', sans-serif
- Use simple, clear icons that are easily understandable across different languages and literacy levels.
- Subtle animations to provide feedback on interactions, such as generating content or completing a lesson, avoiding distracting or unnecessary movements.
